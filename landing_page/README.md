# Cafe Social landing page

Marketing site for Cafe Social — Next.js 15, Tailwind 4, Poppins, EN/DE/ES/HR.

## Development

```bash
cd landing_page
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Environment

Optional store links (shown when set; otherwise badges display "Coming soon"):

```bash
NEXT_PUBLIC_APP_STORE_URL=
NEXT_PUBLIC_PLAY_STORE_URL=
```
